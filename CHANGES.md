# Что изменено

## Логика подбора

- **Прогноз очков.** Форма считается с экспоненциальным затуханием (полураспад — 6 матчей) и сжимается к оценке по цене игрока (вес — 30 эффективных матчей). Добавлены поправка на силу соперника (по результатам матчей, в ограниченных пределах) и вероятность сыграть: после пропусков она восстанавливается постепенно.
- **Бэктест на данных Sports.ru:** RMSE 13,90 → 12,90, MAE 11,03 → 10,18, завышение прогноза +2,52 → +1,45 очка. Для игроков после пропусков: RMSE 15,05 → 12,38, смещение +5,56 → −1,26. Ошибка прогноза доступности (Brier) 0,089 → 0,056. Ранжирование стало точнее у защитников (Spearman 0,229 → 0,266) и нападающих (0,196 → 0,261); у вратарей выборка маленькая (0,461 → 0,402).
- **Замены на неделю.** Точная целочисленная оптимизация по слотам с учётом позиций, бюджета, лимита клуба, 5 трансферов и заблокированных игроков. Результат сверяется с полным перебором в тесте.
- **Время каждой замены:** «сейчас» или «после матча уходящего игрока», и до какого времени нужно успеть (до первого матча новичка).
- **Порядок шагов** подбирается так, чтобы баланс ни на одном шаге не уходил в минус.
- **Подготовительные замены:** свободные трансферы, которые не снижают прогноз текущей недели, но добавляют очки в следующих.
- **Проверка расчёта:** план проверяется по 9 условиям (прирост, бюджет на каждом шаге, трансферы, позиции 2/6/9, лимит клуба после каждой замены, блокировки, точность поиска и др.); в интерфейсе виден итог «N из N условий выполнены».
- **План на месяц** считается за ~1,3 с методом скользящего горизонта (прежний точный расчёт зависал). На живом снимке прибавка +278,6 очка против +262,5 у прежней эвристики.
- **Пул кандидатов** собирается из составов всех соперников по лиге: 205 игроков, 78 из них с полной статистикой (было 30). Детальные данные кэшируются на 15 минут.
- Сравнение кандидата с игроком состава учитывает, чей матч раньше.
- API хранит последний удачный снимок в памяти процесса, поэтому кэш работает и без базы данных. Версия снимка поднята до 7, чтобы старые снимки без нового пула не использовались.

## Дизайн

- Интерфейс полностью переделан по дизайн-системе X.com (тёмная тема Lights out): чёрный фон, тонкие разделители, синий акцент, кнопки-«пилюли», плотная типографика.
- Раскладка X: слева навигация с главной кнопкой «Рассчитать неделю» и карточкой аккаунта, в центре лента с липкой размытой шапкой и вкладками, справа поиск, лига и блок «Кого взять». На мобильных — нижняя панель навигации и плавающая кнопка.
- Профиль команды оформлен как профиль X (баннер, аватар, статистика), состав — как «композер» с чипами игроков, план замен — как тред из шагов, сравнения — как цитаты.
- Адаптив от 390 до 1440 px без горизонтальной прокрутки. Модальные окна закрываются по Esc.
